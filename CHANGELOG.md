# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## 0.1.0

### Added

- Initial package skeleton for `nowbar_flutter`.
- Bundled Inter font family (Regular 400, SemiBold 600, Bold 700).
- Stub public API for the Now Bar widget, components, drag controller,
  metrics, theme, and per-component widgets.
- Test harness that loads the bundled Inter fonts via `FontLoader`.
- Runnable example app depending on the package by path.
